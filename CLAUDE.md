# Desktop Bins Widget

Drive the app with `bins` (the app binary; `bins help`). See `.claude/skills/bins/SKILL.md`. Commands live in
`Sources/DesktopBinsWidget/Agent/AgentCommands.swift`; test them on a Debug build with `APP_STORE=/tmp/<name>`,
which starts a test copy on its own bins, Desktop Bins folder, stand-in Desktop and settings, with no panels on
screen (Release builds ignore it).
